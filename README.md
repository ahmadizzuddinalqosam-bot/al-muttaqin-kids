# Portal Web Al Muttaqin Kids v6.0 (Complete Canon Edition) — Majelis Ta'lim Al Muttaqin

Portal Edukasi Islam Anak — **Semesta Kisah Kampung Al-Muttaqin** di bawah naungan **Majelis Ta'lim Al Muttaqin** (*Biro Publikasi & Kurikulum Media Pembelajaran — Majelis Al-Muttaqin Press*).

## Pembaruan Menyeluruh v6.0
1. **21 Sampul Buku ISO A5 Full-Bleed Berkode Warna Unik**:
   - Seluruh 6 buku inti Batch 1 (`MAM-I-01` s/d `MAM-I-06`) kini memiliki adegan 3D keluarga Al-Muttaqin tersendiri sesuai tema masing-masing (Fiqih di Musholla, Tajwid mengaji bersama, Aqidah menatap langit Ayat Kauniyah, Akhlaq adab salim *Birrul Walidain*, Tarikh berkisah gurun/lentera tanpa wajah Nabi, Buku Kerja menulis di meja belajar).
   - 3 Buku Eksklusif tampil mewah dengan 3 identitas warna & ikon khas: **Iqro Eksklusif** (Hijau Zamrud & Mushaf Rehal), **Imla & Menulis Arab** (Biru Navy Royal & Pena Qalam Emas), dan **Juz 'Amma Eksklusif** (Hijau Tua Mihrab Emas Timbul & Lentera).
   - 12 Buku Batch 2 & Batch 3 (`MAM-I-07` s/d `MAM-I-18`) lengkap dengan warna tema dan rincian bab.
2. **18 Foto Produk Merchandise Individual (`#01` s/d `#18`) — 100% Canon V1.2**:
   - Seluruh 18 kartu produk memiliki foto studio 3D tersendiri (`MAM_MERCH_01_V6.webp` s/d `MAM_MERCH_18_V6.webp`), lengkap dengan karakter Al Qosam, Kak Zahra, & Keluarga Al-Muttaqin pada tas ransel, tote bag, kotak pensil EVA 3D, jurnal A5, tumbler, serta perbaikan Canon V1.2 pada **Celengan Sedekah Subuh (`#12`)** (100% berhijab).
   - **Ketetapan Adab Syar'i Terjaga**: Sajadah Anak (`#09`) murni motif mihrab geometris tanpa ilustrasi wajah.
3. **Skrip Bantu 1-Klik (`tukar_cover_asli.py`)**:
   - Jika ingin menukar sampul web langsung dengan file bentangan cetak A4 lokal di laptop Anda, taruh file `.png`/`.jfif` di folder `cover_asli_lokal` lalu jalankan `python tukar_cover_asli.py` — otomatis memotong 50% sisi kanan depan A5 ke `assets/covers/`.

## Cara Update ke GitHub Pages (`al-muttaqin-kids`)
1. Ekstrak seluruh isi `al-muttaqin-kids-web-github-v6.zip`.
2. Buka repositori `al-muttaqin-kids` → **Add file → Upload files**.
3. Seret seluruh isi hasil ekstrak (`index.html`, `README.md`, `tukar_cover_asli.py`, `assets`, `buku`, `bab`) → **Commit changes**.
4. Tunggu 1–2 menit lalu tekan `Ctrl + Shift + R` di `https://ahmadizzuddinalqosam-bot.github.io/al-muttaqin-kids/`.
